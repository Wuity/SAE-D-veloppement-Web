Valorant Fandom

Agents

Initiateur
Initiateur est l'une des quatres classes dans lesquelles sont répartis les agents de VALORANT. Les compétences des agents de cette classe sont conçues principalement autour de l'entrée sur les sites de pose du spike en forçant le déplacement des adversaires au moment adéquat. Il existe actuellement six Initiateurs
Dueliste
Duelliste est l'une des quatres classes dans lesquelles sont répartis les agents de VALORANT. Les compétences des agents de cette classe leur permettre d'entrer en premier sur les sites, d'occuper l'espace et d'engager les combats La compétence Signature des Duellistes se recharge après deux éliminations, contrairement aux autres classes pour lesquelles il s'agit souvent d'un délai. Il existe actuellement sept Duellistes.
Controleur
Contrôleur est l'une des quatres classes dans lesquelles sont répartis les agents de VALORANT. Les compétences des agents de cette classe sont conçues principalement autour de la réduction de la vision des ennemis Il existe actuellement six Contrôleurs
Sentinelle
Sentinelle est l'une des quatres classes dans lesquelles sont répartis les agents de VALORANT. Les compétences des agents de cette classe sont surtout défensives, avec un accent particulier sur la prise d'informations, le verrouillage des sites et la surveillance des flancs. Il existe actuellement cinq Sentinelles
